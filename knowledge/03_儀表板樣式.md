# 03 儀表板樣式（一頁 HTML，單檔、不連網）

- 底 #0B0B0D、次底 #141417、文字 #F2EEE6、金 #C9A45C／#E3C78A；字體 system-ui（不載外部字體）
- 頂：標題「觀點週刊 · 訂戶月報 YYYY-MM」＋一句總結
- 四個大數字：有效訂戶／到期預警／高風險流失／建議先聯絡
- 三張圖，用純 SVG 或 CSS 條圖（不載圖表函式庫）：
  ① 續訂 Cohort（每月一條，續訂率％）
  ② 流失預警分佈（高風險 vs 到期預警 vs 有效）
  ③ 價值分群（高價值／穩定／沉睡 人數）
- 底：前 20 名「建議先聯絡」表（代號、方案、到期日、風險原因），只有代號沒有個資
- 每個數字下方小字寫算法
