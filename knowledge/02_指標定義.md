# 02 指標定義（每個數字都照這個算，並在產出裡寫出算法）

## 去敏與串接
- 代號：Email → strip → lower → 第一次出現給 U0001、U0002…（三張表共用一張對照表）
- 串接結果要報：三張都有／只在訂閱／只在 App／只在商城 各幾人；三張表合計不重複人數

## 基準日
以 2026-09-20 為「今天」（示範資料的時間點）。

## 指標
| 指標 | 算法 |
|---|---|
| 有效訂戶 | 訂閱表 到期日 ≥ 今天 的人數 |
| 續訂率（Cohort） | 依起始月分組：狀態＝已續訂 ÷ 該批已到期（已到期＋已續訂）人數；只列有 ≥ 5 人到期的月份 |
| 到期預警 | 有效訂戶中，到期日在今天起 60 天內 |
| App 沉睡 | App 表 sessions_30d ＝ 0 |
| 商城沉睡 | 商城表最後一筆已出貨交易距今 > 180 天，或從未購買 |
| **高風險流失** | 到期預警 且（App 沉睡 或 不在 App）且（商城沉睡 或 不在商城） |
| 商城累計消費 | 已出貨交易 數量×單價 加總（退貨不算） |
| 價值分群 | 高價值：訂閱方案為 紙本兩年／紙本+數位／紙本一年 且（商城累計 ≥ 3,000 或 App sessions_30d ≥ 20）；沉睡：App 沉睡 且 商城沉睡 且 近90天開信次數 ≤ 1；其餘：穩定 |
| 建議先聯絡 | 高風險 ∩ 高價值，依到期日近的先 |

## 不做的
不預測、不做機器學習；只做能一句話講清楚的規則。
